# Security

This repository is a personal blog: a static site with no server, no user
accounts, no forms, and no data collection. The build runs in GitHub Actions
and publishes to GitHub Pages.

## Reporting a problem

Please report privately through
[GitHub's private vulnerability reporting](https://github.com/ftrout/ftrout.github.io/security/advisories/new)
rather than opening a public issue.

Useful things to report:

- A way to get content onto the site without a commit to `main`.
- A weakness in the build or deploy workflow, or in a dependency it uses.
- A link on the site that now points somewhere malicious.
- Anything published here that should not have been, such as a credential or
  personal data.

## Not in scope

- Code in blog posts. Snippets are illustrations of an idea, not software this
  repository ships or supports. Point out an error in one with a normal issue.
- GitHub Pages itself. Report platform issues to
  [GitHub](https://bounty.github.com/).
